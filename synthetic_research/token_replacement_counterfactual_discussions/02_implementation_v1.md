# Реализация v1 в PR №7

## Принятый контракт

Первая версия реализует короткий проверяемый пилот без запуска API:

1. Берёт только human-пары с `target=1` и одинаковой категорией.
2. Находит общие токены в `name + values(attributes)` уже существующей эвристикой PR №7.
3. Оставляет пару, только если хотя бы один предложенный токен содержит латинскую букву или цифру.
4. Набирает пилот round-robin по доступным категориям, чтобы случайный порядок не перекосил macro-эксперимент.
5. Передаёт провайдеру только категорию, два имени, два JSON атрибутов и список предложенных токенов. ID и target остаются локально.
6. Принудительно вызывает одну функцию `submit_replacement_decision`. В JSON Schema поле `source_token` имеет динамический `enum` из предложенного списка.
7. Разрешает `status=skip`. При `status=replace` допускает от одной до заданного максимума независимых замен.
8. Повторно валидирует ответ локально. Ответ с непропонованным токеном, дублем source-токена, пустой/равной заменой или пробелами внутри нового токена отклоняется.
9. Для каждой принятой операции создаёт одну positive и одну negative пару. Сторона negative выбирается стабильным хешем.
10. Сохраняет журнал ответов, `synthetic_items.parquet`, `synthetic_pairs.parquet` и manifest с SHA-256.

Alibaba гарантирует для `response_format={"type":"json_object"}` только корректный JSON. Поэтому для ограничения значений используется Function Calling с принудительным выбором функции и JSON Schema, а локальная проверка остаётся обязательной страховкой.

## Безопасный запуск

Подготовить локальный план без API:

```powershell
python scripts\generate_token_replacement_counterfactuals.py `
  --items data\items_human.parquet `
  --pairs data\splits\matches_item_disjoint_70_30_seed42.parquet `
  --output-dir artifacts\token_replacement_counterfactual\pilot
```

Если в файле пар есть колонка `split`, источником по умолчанию служит только `train`, а все товары остальных частей автоматически попадают в локальный deny-list. Это не позволяет случайно взять validation-пару или товар из неё как источник генерации.

Реальный запрос дополнительно требует `--execute`, `--model` и переменную окружения `DASHSCOPE_API_KEY`. До отдельного решения о размере пилота команда `--execute` не запускается.

## Few-shot

CLI принимает необязательный JSON-файл с примерами по категориям. Отсутствие полного набора 3–5 примеров на каждую категорию не блокирует dry-run и тесты, но перед масштабированием такой набор желательно сделать вручную и отдельно отревьюить.
