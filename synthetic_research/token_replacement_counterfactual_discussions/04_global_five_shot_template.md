# Сокращение до пяти общих few-shot

## Решение

Для первого пилота не требуется вручную размечать 60 категорийных примеров. Используются пять общих примеров, которые передаются для любой категории:

1. очевидная замена оптической силы контактных линз;
2. очевидная замена веса упаковки продукта;
3. очевидная замена модели электронного датчика;
4. `skip` для ошибочной positive-пары «чайник — кофемолка»;
5. `skip` для ошибочной или вариантной positive-пары с разной пробой и размером кольца.

Такой набор учит модель трём содержательным типам замен и двум главным причинам отказа, не увеличивая каждый prompt десятками примеров. Категорийные few-shot можно добавить позже только для реально обнаруженных повторяющихся ошибок.

Локальный приватный шаблон:

```text
artifacts/token_replacement_counterfactual/global_five_shot_annotation_template_v1.json
```

В JSON эти примеры находятся в специальной категории `__global__`. Генератор объединяет их с возможными категорийными примерами, строго валидирует заполненные решения и удаляет локальные служебные поля перед созданием provider payload.
