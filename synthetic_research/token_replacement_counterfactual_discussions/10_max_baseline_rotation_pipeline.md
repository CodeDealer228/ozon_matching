# Текущий pipeline: метод Макса + автоматическая ротация моделей

## Что запускаем сейчас

Это базовый, неагрессивный вариант. Идеи с web search, несколькими генераторами,
голосованием и отдельной моделью-валидатором остаются следующими экспериментами и
не входят в текущий запуск.

Для каждой human-train пары с `target=1`:

1. Локальная эвристика находит общие значения в названиях и атрибутах двух карточек.
2. В список `offered_tokens` попадают только общие значения с латиницей или цифрами.
3. Модель через принудительный structured output выбирает до двух независимых замен
   либо возвращает `skip`.
4. `source_token` может быть только одним из предложенных значений; это ограничено
   JSON Schema и повторно проверяется локально.
5. Для каждой принятой замены создаются две пары:
   - замена в обеих карточках — новый positive (`target=1`);
   - замена только в одной карточке — новый negative (`target=0`).
6. Две замены в ответе дают четыре независимых обучающих пары.

Код генерации:
`scripts/generate_token_replacement_counterfactuals.py`.

Класс ротации моделей:
`scripts/alibaba_model_quota_router.py`.

## Few-shot

Финальный локальный набор содержит 60 проверенных примеров: по три на каждую из
20 категорий. Из них 24 показывают безопасную замену, 36 — правильный `skip`.

`bee9a885d1d7144ec35c7802babf8ff538e6e5517608122d67fc9cb14d0e5cd8`.

Перед отправкой локальные ID и заметки удаляются функцией `load_few_shots`.

## Ротация моделей

Модели перебираются в порядке реестра. Переключение происходит только при:

- точном коде исчерпания allocation/free-tier quota;
- точном ответе HTTP 404 с кодом `model_not_found`.

Сетевая ошибка без HTTP-ответа считается неопределённой: запрос фиксируется, но
автоматически не повторяется, чтобы не получить скрытый дубль. Обычная ошибка
валидации также не переключает модель. События исчерпания пишутся в
`model_events.jsonl`, поэтому после перезапуска уже исчерпанные модели пропускаются.

Основной реестр содержит девять моделей до 32B. После него разрешено ранее
согласованное расширение из двух 35B-A3B моделей. 80B в реестр не входит.

Фраза «все 90M» трактуется как попытка использовать доступные бесплатные квоты
всех разрешённых моделей, а не как обещание ровно 90 миллионов токенов. Фактический
расход отдельно суммируется по каждой модели из ответа провайдера.

## Что отправляется провайдеру

Только `category`, `name_1`, `attributes_1`, `name_2`, `attributes_2`,
`offered_tokens` и очищенные few-shot-примеры нужной категории. ID, target,
validation и секреты не отправляются. Источником служит только human-train;
товары validation находятся в deny-list.

## Команда масштабного запуска

```powershell
python scripts\generate_token_replacement_counterfactuals.py `
  --items data\items_human.parquet `
  --pairs data\splits\matches_item_disjoint_70_30_seed42.parquet `
  --source-split train `
  --few-shots artifacts\token_replacement_counterfactual\few_shot_annotation_template_v1.json `
  --model-registry synthetic_research\token_replacement_counterfactual_discussions\model_rotation_v1.json `
  --model-registry synthetic_research\token_replacement_counterfactual_discussions\model_rotation_extension_35b_v1.json `
  --all-eligible `
  --output-dir artifacts\token_replacement_counterfactual\max_baseline_rotation_v1 `
  --execute
```

Без `--execute` команда строит полный локальный план запросов, проверяет утечки и
не обращается к Alibaba.

## Условия остановки

Pipeline останавливается, когда исчерпаны все подходящие human-train positives,
достигнуты квоты всех разрешённых моделей либо возникла неопределённая системная
ошибка, требующая ручной проверки. Журнал позволяет продолжить без повторной
отправки уже завершённых или неопределённых запросов.
