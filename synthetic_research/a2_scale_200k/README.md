# A2 v4: масштабирование на все категории

Эта папка хранит решения и отчёты для генерации по 10 000 A2-примеров на
каждую из 20 категорий canonical human train.

Документы:

1. `01_pipeline_before_launch.md` — зафиксированный до запуска pipeline,
   ограничения, порядок моделей и правила остановки.
2. `02_generation_progress.md` — создаётся/обновляется после запуска и содержит
   фактический прогресс, расход токенов и причины переключения моделей.
3. `03_final_generation_report.md` — появится после достижения цели либо
   исчерпания всех разрешённых квот.

Код и документы можно публиковать. Сырые ответы, исходные пары и собранные
parquet-артефакты остаются локальными.
