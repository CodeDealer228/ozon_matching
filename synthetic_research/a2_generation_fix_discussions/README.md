# История обсуждений исправления A2 generation

Эта папка хранит последовательные варианты проектного решения по улучшению
генерации A2 synthetic hard negatives.

Документы расположены хронологически:

1. `01_codex_prompt_v2_handoff.md` — исходный разбор первого pilot и первое
   предложение Codex по prompt/validator v2, подготовленное для обсуждения.
2. `02_gpt_a2_v3_design_proposal.md` — следующий вариант архитектуры A2 v3,
   полученный после внешнего обсуждения с GPT.
3. `03_codex_a2_v3_review_and_recommendation.md` — критический разбор второго
   варианта с уточнённой рекомендуемой архитектурой и планом pilot.
4. `04_teamlead_review_audit_against_current_state.md` — проверка замечаний
   тимлида из PR #3 относительно текущего состояния A2 v3 и ветки C.

Это исследовательские документы, а не исполняемые инструкции. Актуальное
решение для реализации нужно фиксировать отдельно после согласования.

Важно: документы могут содержать примеры товарных строк из исследуемого
датасета. Секреты, API-ключи и токены в эту папку добавлять нельзя.
