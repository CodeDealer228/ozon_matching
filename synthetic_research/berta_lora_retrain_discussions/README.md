# Обсуждение BERTA: merge старой LoRA и обучение новой LoRA

Эта папка хранит последовательный design review задачи тимлида. Здесь только
обсуждение и зафиксированные решения; до финального согласования Kaggle training
не запускается.

Порядок файлов:

1. `01_codex_initial_design_handoff.md` — факты из репозитория, разбор ошибки
   первого A2-эксперимента и первоначальный план Codex;
2. `02_gpt_design_review.md` — ответ внешнего GPT, который пользователь пришлёт
   следующим сообщением;
3. `03_codex_final_decision.md` — итоговая сверка предложений и точный план
   реализации;
4. после согласования — отдельный implementation/run report с кодом, Kaggle
   версиями, метриками и SHA-256.

Актуальный статус: GPT-review сохранён в файле 02, итоговое заключение Codex —
в файле 03. Обучение не запускалось; требуется подтверждение финального плана.
