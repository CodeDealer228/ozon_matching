# Вариант 2 — fully relaxed C

## Идея

Любой strict/guarded pattern из `negative_patterns` можно применять к товару,
если нужный атрибут найден. Replacement value выбирается из другого train item
той же категории, после чего Qwen свободно переписывает карточку.

Проверяются только формат ответа, отсутствие validation leakage и наличие
изменённого значения.

## Плюсы

- большой объём generation opportunities;
- высокая вариативность;
- мало дорогостоящих отказов после API call.

## Минусы

- donor может относиться к несовместимому product family;
- изменение может создавать физически невозможный товар;
- вместе с target dimension Qwen может незаметно изменить другие факты;
- шум synthetic labels способен превысить пользу большого объёма;
- трудно понять причину изменения validation score.

## Решение

Как основной pipeline вариант не рекомендуется. Он полезен только как верхняя
оценка доступного объёма и источник примеров для ручного исследования.
