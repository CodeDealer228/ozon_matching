# submits/ — собранные сабмиты по семействам

Каждый сабмит — готовый zip (+ иногда распакованная копия) для судейского
стенда. Актуальный лучший результат проекта — `frida/sft_continue/`
(тест 0.487). Сгруппировано по энкодеру:

| Директория | Энкодер | Лучший тест |
|---|---|---|
| `frida/` | FRIDA (823M) — LoRA, full-SFT, продолжение full-SFT | **0.487** |
| `berta/` | BERTA (128.3M, дистилляция FRIDA) | 0.47 |
| `qwen/` | Qwen3-Embedding (bi-encoder) + BERTA-CatBoost комбинации | 0.41 |
| `minilm/` | MiniLM (исходный baseline) | 0.265 (лидерборд, не тест-стенд) |
| `probes/` | пробы разных энкодеров (giga3b, matryoshka и т.д.), не доведены до полноценного сабмита | — |

Реальные тест-скоры (H100 судейский стенд, не Kaggle val) — таблица в
корневом `README.md`.
