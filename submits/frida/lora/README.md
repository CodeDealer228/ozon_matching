# FRIDA + LoRA сабмиты

Сгруппировано по `PAIR_MAX_LENGTH` обслуживания — это главная переменная,
влияющая на тайминг и тест-скор в этой линии (см. `CLAUDE.md` →
"Известные пары val ↔ leaderboard").

| Директория | `PAIR_MAX_LENGTH` | Лучший тест в группе |
|---|---|---|
| `early/` | разное (128/старые) | ранние прогоны, до v2-политики атрибутов — `lora_v2_epoch`: 0.386 |
| `length_128_160/` | 128-160 | человеко-only, короткие длины |
| `length_176/` | 176 | **`tpu_human_llm_best_176_5120`: 0.469** — лучший в LoRA-линии |
| `length_180_192/` | 180-192 | смесь human+LLM, средние длины |
| `length_256/` | 256 | человеко-only, длинный контекст (падает на Check-стадии судейского стенда при полной длине) |

LoRA-линия уступает full-SFT подходу (`../full_sft/`, `../sft_continue/`,
актуальный лучший результат — 0.487) — оставлена для истории/сравнения.
