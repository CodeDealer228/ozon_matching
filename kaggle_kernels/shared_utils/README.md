# Общие утилиты (не привязаны к одному энкодеру)

| Кернел | Назначение |
|---|---|
| `val-per-category-metrics` | пост-анализ per-category val-скоров сохранённого чекпоинта (CPU) |
| `item-length-analysis` | распределение длин полей (name/category/attributes) по всему каталогу — обосновывает char-budget константы |
| `publish-token-cache` | публикация токен-кэша как Kaggle-датасета отдельным шагом |
