# FRIDA — per-category специалисты

Вместо одной модели на все 20 категорий — 20 независимых LoRA-адаптеров
(один backbone, переключаемая LoRA+голова на категорию). Мотивация: метрика
— plain mean по 20 категориям, а positive rate отличается между ними в
7.7 раза.

| Кернел | Примечание |
|---|---|
| `percat-lora` | основная версия (v6-v11 в истории — resume, чекпоинты, RSS-фиксы) |
| `percat-lora-olora` | вариант с OLoRA-инициализацией + меньшим батчем (попытка фикса NaN-расхождения) |
| `percat-lora-nan-diagnose` | диагностический кернел — **сломан по дизайну** (per-block finiteness hooks на TPU/XLA вызывали катастрофическую рекомпиляцию), остановлен, не чинился |

Хронически страдает от NaN-расхождения на большинстве категорий и
host-RAM OOM — полная история в `CLAUDE.md`/`reports/experiment_log.md`.
