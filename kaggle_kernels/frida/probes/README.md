# FRIDA — диагностика и разведка

| Кернел | Назначение |
|---|---|
| `nan-diagnose` | диагностика источника NaN в LoRA-SFT (root-caused: autocast должен открываться внутри `forward()`, не снаружи) |
| `batch-probe` | замер безопасного батч-сайза (НЕ используется на TPU в реальных прогонах — там батч всегда фиксированный, см. `kaggle-experiment-safety`) |
| `char-token-ratio` | замер символов/токен для русского текста через BPE-токенизатор FRIDA |
| `validate-checkpoint` | валидация чекпоинта на val-сплите вне основного тренировочного кода |
| `tpu-embed-cache-human` | кэш эмбеддингов для bi-encoder-подхода (парковано — см. CLAUDE.md "Bi-encoder probes") |
| `head-train` | обучение классификатора поверх кэшированных эмбеддингов (та же bi-encoder-ветка) |
