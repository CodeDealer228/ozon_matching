# FRIDA-кернелы

Все Kaggle-кернелы вокруг `ai-forever/FRIDA` (T5EncoderModel, 823M) — основной
энкодер проекта. Сгруппировано по стадии пайплайна:

| Директория | Что внутри |
|---|---|
| `tokenize/` | Пре-токенизация items (human/LLM scope) в memmap-кэш — вход для всех тренировочных кернелов ниже |
| `lora/` | LoRA SFT прогрессия (человеческие данные) + `lora/continue/` (продолжение на LLM-разметке) |
| `percat/` | Per-category специалисты (20 независимых LoRA-адаптеров вместо одной модели) |
| `full_sft/` | Первый **полный** (не LoRA) файнтюн — текущий стартовый чекпоинт для `full_sft_continue/` |
| `full_sft_continue/` | Продолжение full_sft — общий код + `experiments/` (5 вариантов гиперпараметров) + сборщик сабмитов |
| `probes/` | Диагностика (NaN, батч-сайз, длина в токенах) + разведка bi-encoder-подхода |

**Актуальный лучший результат проекта** — `full_sft_continue/experiments/c-llm3m`
(тест-стенд 0.487). Полная история — `CLAUDE.md` в корне репо.
