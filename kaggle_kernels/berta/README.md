# BERTA-кернелы

`sergeyzh/BERTA` (BertModel, 128.3M, дистилляция FRIDA) — параллельная
кросс-энкодер-ветка. Лучший val проекта (0.7111, ещё не сходился) держал
BERTA; на тест-стенде — 0.47 (лучший результат до FRIDA full-SFT).

| Директория | Что внутри |
|---|---|
| `catboost/` | 3 кернела: leak/noleak A-B тест утечки признаков + top-final вариант головы |
| `training/` | всё остальное — токенизация, SFT, эмбеддинги, hard negatives, утилиты (см. `training/README.md`) |
